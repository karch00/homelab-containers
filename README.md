# Server dockerfiles
Here I will upload and backup the docker images for most of the services running on my homelab.

Sensible/Variable information is redacted and require a .env file to replace the variables.

All servies run behind a proxy regardless of if the service includes its own.

## Service images

> **Forgejo**
> For private git repositories, such as note taking and the likes

> **ItTools**
> Various tools for developers

> **Nextcloud**
> File cloud server, for sharing

> **n8n**
> Personal automation processes

> **Wger**
> Personal fitness tracker

> **Navidrome**
> Personal music streaming from static media

> **Kavita**
> Book, Comic and Manga storing and reading
